# Golf Relax app — luật cho agent

- Stack: pnpm monorepo. `apps/golf` = Expo SDK 57 + Expo Router (chạy Expo Go, chưa dev build). `packages/ds` = design system `@gr/ds`. Chạy: `pnpm -F golf start` → Expo Go quét QR (cùng Wi-Fi; không thấy → `--tunnel`).
- Mọi màu / spacing / radius / size / font trong `apps/golf/app/**` đi qua `useTheme()` hoặc component của `@gr/ds`. **Cấm** literal hex, `fontSize:`, `padding*:`, `margin*:`, `gap:` số. Kiểm: `pnpm check:literals`.
- Key token = **đúng tên Figma**: `t.color('Color/Content/Neutral/Strongest')`, `t.component('Button-Primary/Background/Default')`, `t.space('Spacing/Gap/Medium')`, `t.layout('Margin-Small')`, `<Text variant="Body/Base/DemiBold">`. Không đặt tên mới, không camelCase.
- Không import `packages/ds/src/generated/primitives*` từ app (primitive chỉ để resolve alias).
- Token đổi trong Figma → dump lại theo `packages/ds/tokens/README.md` (use_figma, ≤20 KB/call), `node tokens/compact-to-dtcg.mjs`, `pnpm -F @gr/ds build:tokens`, commit cả `compact/`, `figma/`, `src/generated/`.
- Storybook: `pnpm -F @gr/ds storybook` (http://localhost:6006). Story `packages/ds/src/ui/<Name>/<Name>.stories.tsx` (title `Nhóm/Tên`, tên story tiếng Việt theo variant, `args` = props Figma, `fn()` cho handler); nhóm `Gallery/*` nhúng trang `apps/golf/app/(dev)/ds/*`. Theme light/dark = toolbar. Chụp hàng loạt: `node scripts/shot-storybook.mjs <outDir> [regex-id]`.
- A11y: state của control đi qua `a11yState({checked|selected|disabled|expanded}, role)` / `a11yValue(...)` (`ui/a11y.ts`) — KHÔNG viết `accessibilityState=`/`accessibilityValue=` trực tiếp (react-native-web 0.21 bỏ, chỉ nhận `aria-*`; native cần cả hai). Ô nhập có `accessibilityLabel` (label → placeholder), nút icon có label, ảnh trang trí `aria-hidden`. Outline focus web: `INPUT_RESET` chỉ ở ô đã vẽ state Focused. Gate hàng loạt: `node scripts/audit-storybook.mjs <outDir>` (ảnh sáng/tối 390/430 + focus/hover/pressed thật + màu/font so token + axe) → `report.md`.
- Component `packages/ds/src/ui/<Name>/`: `<name>Styles.ts` pure `(theme, props) → styles` + `.test.ts` (assert token key theo variant) + `<Name>.tsx` + gallery `apps/golf/app/(dev)/ds/<name>.tsx` (thêm vào `GALLERY` ở `index.tsx`). Props = tên Figma camelCase, giá trị Figma nguyên văn (kể cả `"Medium (Base)"`); `State` không là prop (pressed/disabled suy từ Pressable). Mẫu: `ui/Button/buttonStyles.ts`. Spec/Open: `docs/ds/superpowers/specs/2026-09-16-ds-components-design.md` §7 (đợt 1) / §7b (đợt 2) / §7c (đợt 3 composite Golf Insider). Composite dùng lại primitive (`Identity`, `SocialAction`, `BottomSheet`) thay vì vẽ lại.
