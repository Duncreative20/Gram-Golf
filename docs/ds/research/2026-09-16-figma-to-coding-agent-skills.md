# Skill/plugin trên GitHub giúp Figma → Coding Agent tốt hơn

- **Câu hỏi:** Có skill/plugin/prompt pack nào trên GitHub (SKILL.md cho Claude Code, Cursor rules, Codex skill) làm agent chuyển Figma → code tốt hơn 3 baseline đã biết không? Ưu tiên mobile (SwiftUI / Flutter / React Native).
- **Ngày:** 2026-09-16
- **Phương pháp:** WebSearch nhiều truy vấn → với mỗi ứng viên fetch README + raw `SKILL.md` + GitHub API (`/repos/...` lấy sao, license, `pushed_at`). Không dựa vào blog tổng hợp. Mục "chưa xác minh" = không fetch được nguồn gốc.
- **Ghi chú môi trường:** máy này đã cài plugin `figma` chính thức (thấy skill `figma-design-to-code`, `figma-swiftui`, `figma-code-connect`, `figma-implement-motion`… trong danh sách skill của phiên).

## 4. Khuyến nghị cho dự án mobile

Kết luận chung: **không có skill nào trên GitHub vượt hẳn baseline** ở khâu *đọc* Figma — tất cả skill đáng dùng đều gọi MCP chính thức. Giá trị cộng thêm nằm ở 3 chỗ baseline thiếu: **quy trình asset**, **map token/variant vào repo**, và **vòng kiểm định** sau khi code.

| Nếu chọn | Dùng | Lý do |
| --- | --- | --- |
| **SwiftUI** | Plugin `figma` chính thức (`figma-swiftui` + `references/design-to-code.md`) là nền; cài thêm **daetojemax/figma-to-swiftui-skill** | Skill chính thức mạnh nhất về map HIG/Dynamic Type/SF Symbol; daetojemax bù workflow asset @1x/2x/3x, adaptation audit khi sửa màn, và đăng ký Code Connect. Chấp nhận rủi ro không license (cân nhắc copy nội dung vào `.claude/skills/` riêng). Tự thêm bước validate bằng snapshot test vì cả hai đều không tự verify |
| **React Native** | Plugin `figma` chính thức + **jeltehomminga/figma-design-skills** | Duy nhất có verify bằng số trên RN (Metro/CDP), phân loại DRIFT/HARDCODED. Bảng spec `element \| property \| value \| repo token` cũng dùng được cho mọi stack. Còn ít sao (4★) — đọc kỹ SKILL.md trước khi tin |
| **Flutter** | Plugin `figma` chính thức + tự viết skill map widget (lấy mẫu từ AdhamHashim/Flutter_Base) ; **mhmzdev/figma-flutter-mcp** chỉ khi không có Dev Mode seat | Không có skill Flutter public nào có verify loop; VGV giữ kín. figma-flutter-mcp chỉ là MCP thay Framelink với gợi ý widget, tự nhận chỉ hợp MVP |
| Mọi stack | Chạy **bergside/figma-design-skills-plugin** (hoặc southleft skills export token) một lần để có `DESIGN.md`/token file trong repo; mượn ý loop RMSE của gbasin nếu muốn tự viết bước so screenshot | Skill `figma-create-design-system-rules` chính thức đã biến mất khỏi `main`; cần nguồn thay thế để agent biết token của dự án |
